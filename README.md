- **한 일** :
  - "쌓여 있는 방대한 Jira 데이터가 있는데, 왜 같은 문의에 매번 사람이 답하는가"에서 시작했습니다. 문의가 오면 사내 지식과 GitLab 소스, 비슷한 이슈를 대조해 근거가 붙은 1차 답변을 답니다.

  - GitLab 소스를 상한 안에서 읽어 **RAG 코드 인덱스**를 만듭니다. LLM이 고른 파일 경로는 실제로 있는지 다시 확인합니다.
  - 담당자 답변은 `_pending` 폴더에 넣고 관리자가 옮겨야 검색에 잡히게 했습니다. 실패한 분석은 **Kafka DLT**에 보관했다가 60분 뒤 다시 처리합니다.

  - 메일 도메인 구축 요청을 접수, **담당자 승인**, 예약 재확인, A10/WBlock 등록, 보상, 수동검토 상태로 관리합니다. webhook에 찍힌 사람을 믿지 않고 Jira를 다시 조회합니다.
