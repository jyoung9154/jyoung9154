- **기간** : 2026.03 ~ 
- **기술스택** : React, Capacitor, Android, Firebase (Firestore, Auth, Storage), GitHub Actions, Fastlane
- **개요** : 숙소 호스트들을 위한 관리 효율화 플랫폼. 숙소 관리 프로세스를 자동화하고 단기임대 특화 하이브리드 앱 제공.
- **담당 역할 및 성과** :
  - **CI/CD 파이프라인 구축**: GitHub Actions와 Fastlane을 연동하여 코드 푸시 시 Android 빌드가 자동 수행되도록 자동화 프로세스 설계.

  - **안드로이드 배포 최적화**: JDK 21 기반 빌드 환경 구성 및 보안 키(Keystore) 관리 자동화.

### 💌 남녀분석보고서 (AI 뉴스레터 서비스)
- **기간** : 2024.12 ~ 현재 (운영 중)
- **기술스택** : Next.js 14, Supabase, Gemini 2.5 Flash, GLM-4.5, Leonardo.ai, GitHub Actions, PWA, Coupang Affiliate API
- **개요** : 2030 남녀의 심리를 분석하여 공감과 해답을 제공하는 스토리텔링형 AI 자동 뉴스레터 서비스
- **주요 기능** :
    - **AI 스토리텔링 뉴스레터**: 2030 남녀 심리 분석 기반의 리얼리티 연애 에피소드 자동 생성 및 발송.
    - **커뮤니티 밀착형 콘텐츠**: 블라인드, 네이트판 스타일의 구어체 및 유행어를 반영한 15종의 AI 타이틀 시스템.
    - **이미지 갤러리/아카이브**: 생성된 모든 에피소드와 AI 일러스트를 한눈에 확인할 수 있는 웹 대시보드.
    - **구독 및 알림 시스템**: 이메일 기반 뉴스레터 구독/해지 및 자동 발송 프로세스.
    - **수익형 커머스 연동**: 에피소드 주제별 관련 상품(쿠팡) 자동 큐레이션 및 링크 제공.

- **주요 성과** :
    - **멀티 LLM 파이프라인**: Gemini 2.5 Flash 및 GLM-4.5-Flash를 활용한 무료 AI 데일리 뉴스레터 생성 시스템 구축 및 폴백(Fallback) 로직 구현.
    - **프롬프트 엔지니어링**: 15가지 커뮤니티 특화 제목 패턴 및 개인화된 구어체 스타일 프롬프트를 설계하여 AI 티 나지 않는 고품질 콘텐츠 생산.
    - **이미지 생성 자동화**: Leonardo.ai 및 Hugging Face API를 연동하여 상황별 맞춤 일러스트 자동 생성 및 Supabase Storage 업로드 자동화 프로세스 완성.
    - **완전 자동화 운영**: GitHub Actions를 통한 뉴스레터 생성, 정제, 발송(Nodemailer/Resend) 및 DB 동기화 등 전 과정 무인 운영 환경 구축.
    - **수익화 모델 통합**: 콘텐츠 키워드 기반 Coupang Affiliate 상품 자동 매칭 시스템으로 서비스 운영 수익화 기반 마련.
